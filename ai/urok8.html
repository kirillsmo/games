ИИ внутри игры: Змейка играет сама

Что ты увидишь Змейку, которая сама охотится за яблоками. Её «мозг» — это три простых правила и обычный if. Так ты поймёшь разницу между игровым ИИ и чат-ботом. Файл: snake_bot.py

Каждый ход бот смотрит на три клетки вокруг головы и выбирает:

📝 Мозг бота — весь код

def is_safe(cell, snake):
    """Клетка безопасна, если она в поле и в ней нет тела змейки."""
    x, y = cell
    inside = 0 <= x < COLS and 0 <= y < ROWS
    return inside and cell not in snake


def distance(a, b):
    """Сколько шагов до цели, если ходить только по клеткам (без диагоналей)."""
    return abs(a[0] - b[0]) + abs(a[1] - b[1])


def bot_choose(snake, direction, food):
    """МОЗГ БОТА: выбирает направление на этот ход."""
    head_x, head_y = snake[0]
    dx, dy = direction
    options = [(dx, dy), (dy, -dx), (-dy, dx)]   # вперёд, налево, направо

    best = direction          # если хороших ходов нет — едем прямо (и проиграем)
    best_dist = None
    for d in options:
        cell = (head_x + d[0], head_y + d[1])
        if not is_safe(cell, snake):
            continue                              # туда нельзя — пропускаем
        dist = distance(cell, food)
        if best_dist is None or dist < best_dist:
            best, best_dist = d, dist
    return best

А в главном цикле — всего одна новая строчка: бот вместо стрелок выбирает direction.

    if bot_on and not game_over:

🔍 Что тут интересного

Поворот «налево» и «направо» без if

Если едем вправо (1, 0), то (dy, -dx) = (0, -1) — это вверх, то есть налево от нас. А (-dy, dx) = (0, 1) — вниз, направо. Трюк работает для любого направления — проверь на бумажке!

Расстояние «как такси»

distance складывает шаги по x и по y. Так считают расстояние в городе с кварталами, где нельзя срезать по диагонали, — его называют «манхэттенским».

Ответ Бот видит только на один шаг вперёд. Он сворачивает к яблоку и заезжает в «мешок» — закрытый карман из своего же тела, откуда нет выхода. В среднем он набирает около 28 очков.
